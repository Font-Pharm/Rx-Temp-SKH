# ระบบบันทึกอุณหภูมิห้องยาและตู้เย็น — โค้ด Google Apps Script

กลุ่มงานเภสัชกรรม โรงพยาบาลศีขรภูมิ

เว็บแอป Google Apps Script สำหรับบันทึกอุณหภูมิและความชื้นของห้องยาและตู้เย็นเก็บยา
พร้อมแดชบอร์ดและรายงานทางการ (พิมพ์ / PDF) โดยใช้ Google Sheets เป็นฐานข้อมูล

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ฝั่งเซิร์ฟเวอร์: อ่าน/เขียนชีต ตรวจสอบข้อมูล ตั้งค่าระบบ |
| `index.html` | หน้าเว็บทั้งหมด: ฟอร์มบันทึก แดชบอร์ด รายงาน |
| `tailwind.config.js`, `tailwind.input.css` | ใช้สร้าง CSS ที่ฝังใน `index.html` ใหม่เมื่อแก้หน้าตา |

> โฟลเดอร์นี้อยู่ใน repository แบบ Public จึง **ไม่มี** รายชื่อเจ้าหน้าที่และ ID ของ Google Sheet อยู่ในโค้ด
> รายชื่ออยู่ในชีต `ตั้งค่า` และ ID อยู่ใน Script Properties ของโปรเจกต์ Apps Script เท่านั้น

## ติดตั้ง / อัปเดต

1. เปิดโปรเจกต์ Apps Script วางเนื้อหา `Code.gs` และไฟล์ HTML ชื่อ `index` (เนื้อหาจาก `index.html`)
2. **ครั้งแรกเท่านั้น:** ⚙️ Project Settings → Script properties → **Add script property**
   - Property: `SHEET_ID`
   - Value: ID ของ Google Sheet (ส่วนของลิงก์ระหว่าง `/d/` กับ `/edit`)
3. ตั้ง Timezone ของ Sheet เป็น **(GMT+07:00) Bangkok** (File → Settings)
4. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**
   (อย่ากด New deployment เพราะลิงก์ `/exec` จะเปลี่ยน)

ถ้าลืมข้อ 2 หน้าเว็บจะขึ้นข้อความแดง "ยังไม่ได้ตั้งค่า SHEET_ID" พร้อมวิธีแก้

## ชีต `ตั้งค่า`
แก้ไขในชีตนี้แล้วรีเฟรชหน้าเว็บได้เลย ไม่ต้อง deploy ใหม่

| ประเภท | ชื่อ | รายละเอียด | สีกราฟ | ใช้งาน | เวลาราชการ | ไม่เก็บช่วงเวลา |
|---|---|---|---|---|---|---|
| ห้องยา | ชื่อห้องยา | ห้องยาหลักที่สังกัด (เฉพาะจุดย่อย เช่น Sub-Stock) | (ไม่ใช้แล้ว) | ☑ | ☑ = เก็บเฉพาะเวลาราชการ | เช่น `00.30` |
| ตู้เย็น | ชื่อตู้เย็น | ห้องยาที่ตู้สังกัด | (ไม่ใช้แล้ว) | ☑ | ☑ = เก็บเฉพาะเวลาราชการ | เช่น `00.30` |
| ช่วงเวลา | เช่น `09.00 น. (เวรเช้า)` | – | – | ☑ | ☑ = อยู่ในเวลาราชการ | – |
| ผู้บันทึก | ชื่อ-นามสกุล | ตำแหน่ง/กลุ่ม | – | ☑ | – | – |
| เกณฑ์ | ชื่อเกณฑ์ (ห้ามแก้) | ตัวเลข | – | ☑ | – | – |
| วันหยุด | วันที่ | ชื่อวันหยุด | – | ☑ | – | – |

- เอาเครื่องหมาย "ใช้งาน" ออกเพื่อปิดรายการโดยไม่ต้องลบแถว
- **ห้ามเปลี่ยนชื่อ** ห้องยา/ตู้เย็น/ช่วงเวลาที่มีข้อมูลแล้ว เพราะระบบจับคู่ข้อมูลด้วยชื่อ
- ควร Protect ชีตนี้ให้แก้ได้เฉพาะผู้ดูแล

### จุดที่เก็บข้อมูลเฉพาะวันและเวลาราชการ
จุดที่ติ๊กคอลัมน์ "เวลาราชการ" ต้องบันทึกเฉพาะ **วันจันทร์–ศุกร์ที่ไม่ใช่วันหยุด** และเฉพาะ **ช่วงเวลาที่ติ๊กไว้**
(ค่าเริ่มต้น: 09.00 และ 15.00 น.)

ค่าเริ่มต้นที่ติ๊กไว้: ห้องยานอกเบอร์ 7, Sub-Stock OPD 7, ห้องยา Premium 5/2,
ตู้เย็น OPD 7 - Hitachi, ตู้เย็น OPD 7 - Samsung, ตู้เย็น OPD P.5/2 - No. 1

- ยังบันทึกนอกเวลาได้ (เช่น เปิดบริการพิเศษ) ค่าที่บันทึกจะแสดงในกราฟและรายงานตามปกติ
- ถ้าไม่บันทึกนอกเวลา **ไม่นับว่าขาดบันทึก** (ใช้กับข้อมูลทุกช่วงเวลา รวมย้อนหลัง)
- ในรายงาน จุดเหล่านี้มีเครื่องหมาย † และภาคผนวกแสดงวันหยุดเป็นแถวสีเทา

### จุดที่เก็บทุกวันแต่ไม่เก็บบางช่วงเวลา (‡)
คอลัมน์ "ไม่เก็บช่วงเวลา" ของแถวห้องยา/ตู้เย็น ใส่เวลาที่จุดนั้นไม่ต้องบันทึก **ทุกวัน รวมวันหยุด**
เช่น `00.30` หรือหลายเวลา `00.30, 20.00` (พิมพ์ `0:30` หรือชื่อเวรเต็มก็ได้)

ค่าเริ่มต้น: ห้องยาในเบอร์ 7, ตู้เย็น IPD 1 - Toshiba, ตู้เย็น IPD 2 - Mitsubishi ไม่เก็บเวรดึก 00.30 น.
(บันทึกวันละ 3 ครั้ง: 09.00, 15.00, 20.00 น.)

- ยังบันทึกช่วงเวลานั้นได้ แต่ถ้าไม่บันทึกไม่นับว่าขาด (ใช้กับข้อมูลทุกช่วงเวลา รวมย้อนหลัง)
- ในรายงาน จุดเหล่านี้มีเครื่องหมาย ‡

### วันหยุดราชการ
- **เสาร์-อาทิตย์** ระบบรู้เองอัตโนมัติ ไม่ต้องใส่
- **วันหยุดอื่น** (นักขัตฤกษ์ ชดเชย วันหยุดพิเศษ) เพิ่มเป็นแถวประเภท `วันหยุด`
  - ช่อง "ชื่อ" = วันที่ พิมพ์เป็น `2027-01-01` หรือ `01/01/2570` ก็ได้
  - ช่อง "รายละเอียด" = ชื่อวันหยุด
- ระบบใส่วันหยุดปีงบประมาณ 2569–2570 ให้แล้ว รายการที่มีคำว่า **"รอประกาศ ครม."** เป็นการคาดการณ์
  ตามวันหยุดตามประเพณี ให้ตรวจสอบและแก้เมื่อ ครม. ประกาศปฏิทินวันหยุดราชการปี 2570
- ใส่เฉพาะวันหยุดที่ใช้กับจังหวัดสุรินทร์ (ไม่ใส่วันหยุดเฉพาะกรุงเทพฯ)

## ชีตข้อมูลตามปีงบประมาณ
ข้อมูลแยกเป็นชีตละ 1 ปีงบประมาณ (1 ต.ค. – 30 ก.ย.) เช่น `ข้อมูลปีงบประมาณ 2570` = 1 ต.ค. 2569 – 30 ก.ย. 2570

- ระบบสร้างชีตปีใหม่เองเมื่อมีการบันทึกตั้งแต่วันที่ 1 ตุลาคม
- การตรวจบันทึกซ้ำและการดึงข้อมูลอ่านเฉพาะชีตของปีที่เกี่ยวข้อง ความเร็วจึงไม่ลดลงตามจำนวนปี
- คอลัมน์: Timestamp · ประเภทแบบฟอร์ม · วันที่บันทึก · ช่วงเวลา · ชื่อห้องยา/ตู้เย็น · อุณหภูมิ(C) · ความชื้น(%RH) · ผู้บันทึก
- ชีต `เก็บข้อมูลทั้งหมด` (ระบบรุ่นก่อน) ถูกคัดลอกแยกตามปีครั้งเดียว และเก็บไว้เป็นสำรอง

## กราฟ
- **ห้องยา** มี 2 กราฟ: อุณหภูมิ (บน) และความชื้น (ล่าง) แต่ละกราฟมีแกนเดียว **ตู้เย็น** มีกราฟอุณหภูมิ
- ใต้ชื่อกราฟระบุช่วงปกติ เช่น "อุณหภูมิ (°C) · ช่วงปกติ 15–25 °C"
- สีมีความหมายเหมือนกันทุกกราฟ:

| สี | ความหมาย |
|---|---|
| น้ำเงิน | อุณหภูมิ |
| ฟ้าเข้ม | ความชื้น |
| เส้นประ + แถบสีเขียวจาง | ช่วงปกติ พร้อมตัวเลขเกณฑ์ที่ปลายขวาของเส้น เช่น "สูงสุด 25 °C" |
| จุดสีแดง (ใหญ่กว่าปกติ) | ค่านอกเกณฑ์ |

- กดชื่อ "ช่วงปกติ" ใต้กราฟเพื่อซ่อน/แสดงเส้นเกณฑ์
- คอลัมน์ "สีกราฟ" ในชีตตั้งค่าไม่ใช้แล้ว (ทุกตู้เย็นใช้สีน้ำเงินเหมือนกันเพื่อให้อ่านง่าย)

## แก้ไขหน้าตา (Tailwind CSS)
ถ้าเพิ่ม class ของ Tailwind ที่ยังไม่เคยใช้ ต้องสร้าง CSS ใหม่ (ต้องมี Node.js) โดยรันในโฟลเดอร์นี้:

```bash
npx tailwindcss@3 -c tailwind.config.js -i tailwind.input.css -o tailwind.out.css --minify
```

แล้วนำเนื้อหา `tailwind.out.css` ไปแทนที่ CSS เดิมใน `<style id="tailwind">` ท้าย `<head>` ของ `index.html`
