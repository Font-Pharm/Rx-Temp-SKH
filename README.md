# ระบบบันทึกอุณหภูมิห้องยาและตู้เย็น — กลุ่มงานเภสัชกรรม โรงพยาบาลศีขรภูมิ

เว็บแอป Google Apps Script สำหรับบันทึกอุณหภูมิและความชื้นของห้องยาและตู้เย็นเก็บยา
พร้อมแดชบอร์ดและรายงานทางการ (พิมพ์ / PDF) โดยใช้ Google Sheets เป็นฐานข้อมูล

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ฝั่งเซิร์ฟเวอร์: อ่าน/เขียนชีต ตรวจสอบข้อมูล ตั้งค่าระบบ |
| `index.html` | หน้าเว็บทั้งหมด: ฟอร์มบันทึก แดชบอร์ด รายงาน |
| `tailwind.config.js`, `tailwind.input.css` | ใช้สร้าง CSS ที่ฝังใน `index.html` ใหม่เมื่อแก้หน้าตา |

## ติดตั้ง

1. สร้างโปรเจกต์ Apps Script ใหม่ (หรือเปิดโปรเจกต์เดิม)
2. วางเนื้อหา `Code.gs` และสร้างไฟล์ HTML ชื่อ `index` แล้ววางเนื้อหา `index.html`
3. แก้ `TARGET_SHEET_ID` ใน `Code.gs` ให้เป็น ID ของ Google Sheet ที่ใช้
4. ตั้ง Timezone ของ Sheet เป็น **(GMT+07:00) Bangkok** (File → Settings)
5. **Deploy → New deployment → Web app** แล้วเลือกสิทธิ์การเข้าถึงที่เหมาะสม

เปิดหน้าเว็บครั้งแรก ระบบจะสร้างชีต `ตั้งค่า` ให้อัตโนมัติ

## โครงสร้างข้อมูลใน Google Sheet

### ชีต `ตั้งค่า`
แก้ไขรายชื่อห้องยา ตู้เย็น ช่วงเวลา ผู้บันทึก และเกณฑ์ได้ในชีตนี้ แล้วรีเฟรชหน้าเว็บ ไม่ต้อง deploy ใหม่

| ประเภท | ชื่อ | รายละเอียด | สีกราฟ | ใช้งาน |
|---|---|---|---|---|
| ห้องยา | ชื่อห้องยา | ห้องยาหลักที่สังกัด (เฉพาะจุดย่อย เช่น Sub-Stock) | – | ☑ |
| ตู้เย็น | ชื่อตู้เย็น | ห้องยาที่ตู้สังกัด | เช่น `#3b82f6` | ☑ |
| ช่วงเวลา | เช่น `09.00 น. (เวรเช้า)` | – | – | ☑ |
| ผู้บันทึก | ชื่อ-นามสกุล | ตำแหน่ง/กลุ่ม | – | ☑ |
| เกณฑ์ | ชื่อเกณฑ์ (ห้ามแก้) | ตัวเลข | – | ☑ |

- เอาเครื่องหมาย "ใช้งาน" ออกเพื่อปิดรายการโดยไม่ต้องลบแถว
- **ห้ามเปลี่ยนชื่อ** ห้องยา/ตู้เย็น/ช่วงเวลาที่มีข้อมูลแล้ว เพราะระบบจับคู่ข้อมูลด้วยชื่อ
- ควร Protect ชีตนี้ให้แก้ได้เฉพาะผู้ดูแล

### ชีตข้อมูลตามปีงบประมาณ
ข้อมูลแยกเป็นชีตละ 1 ปีงบประมาณ (1 ต.ค. – 30 ก.ย.) เช่น `ข้อมูลปีงบประมาณ 2570` = 1 ต.ค. 2569 – 30 ก.ย. 2570

- ระบบสร้างชีตปีใหม่เองเมื่อมีการบันทึกตั้งแต่วันที่ 1 ตุลาคม
- การตรวจบันทึกซ้ำและการดึงข้อมูลอ่านเฉพาะชีตของปีที่เกี่ยวข้อง ความเร็วจึงไม่ลดลงตามจำนวนปี
- คอลัมน์: Timestamp · ประเภทแบบฟอร์ม · วันที่บันทึก · ช่วงเวลา · ชื่อห้องยา/ตู้เย็น · อุณหภูมิ(C) · ความชื้น(%RH) · ผู้บันทึก

### ชีต `เก็บข้อมูลทั้งหมด` (ระบบรุ่นก่อน)
ถ้ามีอยู่ ระบบจะคัดลอกข้อมูลแยกลงชีตปีงบประมาณ **ครั้งเดียว** โดยอัตโนมัติ
ชีตเดิมไม่ถูกลบหรือแก้ไข เก็บไว้เป็นสำรอง และจะไม่ถูกบันทึกเพิ่มอีก

## แก้ไขหน้าตา (Tailwind CSS)

CSS ของ Tailwind ถูกสร้างล่วงหน้าเฉพาะ class ที่ใช้อยู่ แล้วฝังใน `<style id="tailwind">` ท้าย `<head>` ของ `index.html`
ถ้าเพิ่ม class ของ Tailwind ที่ยังไม่เคยใช้ ต้องสร้างใหม่ (ต้องมี Node.js):

```bash
npx tailwindcss@3 -c tailwind.config.js -i tailwind.input.css -o tailwind.out.css --minify
```

จากนั้นนำเนื้อหา `tailwind.out.css` ไปแทนที่ CSS เดิมใน `<style id="tailwind">`
(class ที่เขียนเองใน `<style>` แรกของไฟล์ใช้ได้ทันที ไม่ต้องสร้างใหม่)

## ใช้ร่วมกับ GitHub ผ่าน clasp

```bash
npm install -g @google/clasp
clasp login
clasp clone <Script ID>      # ดู Script ID ที่ Project Settings ในหน้า Apps Script
# แก้ไฟล์ → clasp push → git commit / git push
```
