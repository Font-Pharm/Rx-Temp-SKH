# Rx-Temp-SKH

ระบบบันทึกอุณหภูมิห้องยาและตู้เย็น กลุ่มงานเภสัชกรรม โรงพยาบาลศีขรภูมิ

| ส่วน | อยู่ที่ | ใช้ทำอะไร |
|---|---|---|
| หน้าแอปบนมือถือ (GitHub Pages) | ไฟล์ในโฟลเดอร์หลัก: `index.html`, `manifest.webmanifest`, `sw.js`, ไอคอน | หน้าห่อที่แสดงระบบจริงในกรอบ และติดตั้งเป็นแอปบน Android/iPhone ได้ |
| โค้ดระบบ (Google Apps Script) | [`apps-script/`](apps-script/) | ฟอร์มบันทึก แดชบอร์ด รายงาน และการเชื่อมกับ Google Sheets |

วิธีติดตั้งและตั้งค่าระบบ ดู [`apps-script/README.md`](apps-script/README.md)

ไฟล์ในโฟลเดอร์ `apps-script/` ต้องนำไปวางในโปรเจกต์ Apps Script และ Deploy จึงจะมีผล
การแก้ไฟล์บน GitHub อย่างเดียวไม่ทำให้ระบบที่ใช้งานจริงเปลี่ยน
